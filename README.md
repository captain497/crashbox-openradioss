# crashbox-openradioss

OpenRadioss models and scripts for an AI-assisted auxetic crash box study (EG6011 capstone).

- `scripts/gen_baseline.py`: builds the baseline AA6061-T6 square tube deck (placeholder geometry).
- `.github/workflows/fetch-openradioss.yml`: downloads the official OpenRadioss Linux release and records its SHA-256 checksum.
